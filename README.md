# POBUNK

ПО для управления бункером на CC:Tweaked 1.16.5.

## Возможности

- Пульт управления с монитором или обычным экраном компьютера.
- PIN-защита оператора.
- Управление главной дверью.
- Управление освещением.
- Управление вентиляцией.
- Ручная тревога.
- Аварийный режим `LOCKDOWN`: дверь закрывается, тревога включается, свет и вентиляция включаются.
- Вход аварийной кнопки через redstone.
- Вход датчика движения.
- Журнал событий.
- Управление через модем по защищённому каналу и паролю.
- Автоматический запуск после перезагрузки.

## Установка

В компьютере CC:Tweaked с включённым HTTP API выполните:

```text
wget run https://raw.githubusercontent.com/Frez7373/POBUNK/main/install.lua
```

Установщик скачает `config.lua`, `bunker.lua` и `startup.lua`, затем перезагрузит компьютер.

## PIN

По умолчанию: `2580`

После установки обязательно измените `pin` в `/config.lua`.

## Подключение

Стандартная конфигурация:

- `front` — управление основной дверью.
- `back` — освещение.
- `left` — вентиляция.
- `bottom` — сирена/тревога.
- `top` — датчик движения.
- `right` — аварийная кнопка.

Можно изменить стороны в `/config.lua`.

Монитор и модем определяются автоматически через `peripheral.find()`.

## Удалённые команды

Канал по умолчанию: `7310`.

Пароль по умолчанию: `1234`.

Доступные действия: `status`, `lock`, `unlock`, `lights`, `ventilation`, `alarm`, `lockdown`, `clear`.

Пример Lua-сообщения:

```lua
rednet.send(id, {password="1234", action="status"}, 7310)
```

Для реальной игровой сборки рекомендуется поменять пароль удалённого управления и PIN.
